# Plank Run

Держи планку — управляй игрой корпусом. Веб-приложение распознаёт тебя через камеру
(MediaPipe, прямо в браузере, видео никуда не отправляется) и превращает планку в игру:
шар летит по тоннелю, ты сдвигаешь корпус и проводишь его через ворота. Таймер идёт,
только пока техника в порядке.

Подробный разбор идеи, ограничений и подводных камней: **[ANALYSIS.md](ANALYSIS.md)**.

## Запуск

Камера в браузере работает только по **HTTPS** или на **localhost**, поэтому открыть
`index.html` двойным кликом не выйдет. Нужен любой статический сервер.

```bash
cd plank-run
npx serve .            # или: python3 -m http.server 8080
# открыть http://localhost:3000 (или :8080)
```

Чтобы играть с телефона, нужен HTTPS. Варианты:

- **GitHub Pages** / **Netlify Drop** / **Vercel**: залить папку как статический сайт;
- локально: `npx serve .` + туннель (`cloudflared tunnel --url http://localhost:3000`).

Без камеры можно посмотреть игру в **демо-режиме**: стрелки или мышь — руль, пробел —
имитация срыва техники.

### Офлайн / без CDN

По умолчанию MediaPipe грузится с jsDelivr, а модели — с серверов Google.
Чтобы держать всё у себя:

```bash
./scripts/fetch-vendor.sh   # скачает ~40 МБ в ./vendor
# открыть с параметром ?local, например http://localhost:3000/?local
```

## Как играть

1. Выбери, где стоит камера:
   - **Спереди** — телефон на полу в 50–80 см перед руками, экраном к тебе (обопри на книгу).
     Камера следит за лицом. Рулишь сдвигом корпуса влево-вправо (или вверх-вниз).
   - **Сбоку** — устройство в 2–3 м сбоку, всё тело в кадре. Строгая проверка провисания
     и подъёма таза, руль — качание вперёд-назад.
2. Нажми «Начать» и встань в планку. Когда приложение поймает позицию и ты замрёшь на
   секунду, оно откалибруется само. Дальше отсчёт 3-2-1 и старт.
3. Срыв техники ставит игру на паузу с подсказкой голосом. Вернёшься в позицию — игра продолжится.
   Если нарушение длится дольше 4 с, подход заканчивается.

Клавиши во время игры: **Esc** — закончить, **R** — перекалибровать, **D** — отладочная
панель с метриками, **C** — показать/скрыть камеру.

Параметры URL: `?debug` — сразу показать метрики, `?cpu` — не использовать GPU,
`?local` — модели из `./vendor`.

## Устройство кода

Без сборки и зависимостей: чистые ES-модули.

| Файл | Что делает |
|---|---|
| `js/pose.js` | камера (`getUserMedia`), MediaPipe Face Detector / Pose Landmarker, откат GPU→CPU |
| `js/plank.js` | анализ: признаки из точек, проверки техники, калибровка, сигнал управления |
| `js/filters.js` | One Euro filter (сглаживание) и дебаунс состояний |
| `js/game.js` | игра: ворота, монеты, сложность, отрисовка на canvas |
| `js/main.js` | экраны, фазы подхода (калибровка → отсчёт → игра ↔ пауза → итог), HUD |
| `js/audio.js` | звуки (WebAudio) и голосовые подсказки (speechSynthesis) |
| `js/storage.js` | настройки и история в localStorage |
| `js/config.js` | откуда грузить MediaPipe и модели |

## Тесты

`test/` — синтетический сквозной тест. 3D-персонаж ставится в планку с заданными ошибками
(провис, «пик», сдвиги, вставание), рендерится в видео, и это видео подаётся в Chromium
как фейковая веб-камера.

```bash
./scripts/fetch-vendor.sh
cd test && npm install
npx http-server .. -p 8765 &              # раздаёт корень проекта
# модели персонажей:
curl -o assets/Michelle.glb https://raw.githubusercontent.com/mrdoob/three.js/dev/examples/models/gltf/Michelle.glb
node render-videos.mjs                     # → out/front.y4m, out/side.y4m
node e2e.mjs front 45                      # приложение + фейковая камера, сводка по сегментам
node e2e.mjs side 50
node ui.mjs                                # демо-режим и скриншоты экранов
```

Нужен Playwright (`npm i -g playwright`) и ffmpeg.
