# tools/tts — голос тренера (Gemini TTS → .m4a)

Скрипт `generate.mjs` заранее озвучивает подсказки тренера бесплатным Gemini TTS и кладёт их файлами:
`assets/voice/<голос>/<id>.m4a` + `assets/voice/manifest.json` (их читает `js/voice.js`).
Тексты берутся из `js/voice-lines.js` (`export const VOICE_LINES = { id: 'текст', … }`, годится и `LINES`).
Решения по формату — PLAN §8.8 и `docs/plan/spec-visual-art.md` §8.1.

Нужны Node 22 и `ffmpeg`/`ffprobe` в PATH. npm-зависимостей нет.

## Ключ

Ключ Gemini API — **только вне репозитория**: переменная `GEMINI_API_KEY`, или путь к файлу с ключом в
`GEMINI_API_KEY_FILE` / `--key-file`. Скрипт не печатает ключ и не пишет его в логи, кэш и манифест.
`.env` в корне сейчас **не** в `.gitignore`, поэтому ключ туда не кладём. Free tier может читать входы:
в TTS идут только публичные фразы, без имён и данных пользователей.

## Команды

```sh
# все подсказки одним голосом (по умолчанию модель gemini-3.1-flash-tts-preview)
node tools/tts/generate.mjs --voice Kore --lines all --model gemini-3.8-flash-tts --out assets/voice

# только некоторые строки (после правки текста в js/voice-lines.js)
node tools/tts/generate.mjs --voice Kore --lines p_go,p_rest --model gemini-3.8-flash-tts

# образцы для выбора голоса: 10 фраз → voices/samples/<голос>/<n>.m4a + samples.json
node tools/tts/generate.mjs --samples --voice Kore,Aoede,Leda,Puck,Charon,Fenrir

# проверка качества уже готовых файлов (без запросов к API)
node tools/tts/generate.mjs --check            # assets/voice
node tools/tts/generate.mjs --check --samples  # voices/samples

# посмотреть пачки и промпты, ничего не отправляя
node tools/tts/generate.mjs --lines all --dry-run
```

Полезные флаги: `--batch 13` (строк в одном запросе), `--max-requests 5` (жёсткий лимит на запуск),
`--min-interval 21` (секунд между запросами), `--bitrate 40k`, `--lufs -16`, `--tp -1.5`, `--pad-ms 40`,
`--default <голос>` (поле `default` в манифесте), `--force` (перекодировать из кэша), `--fresh`
(игнорировать кэш, тратит запросы), `--cache <папка>`, `--style "<english direction>"` / `--no-style`,
`--lines-file a.js,b.js` (несколько таблиц, сливаются по порядку),
`--as <метка>` (с `--samples` и одним голосом: имя папки, например `Kore-3.8` для сравнения моделей).
Полный список — `--help`.

Уже готовая и не изменившаяся строка (тот же текст, та же модель, файл на месте) пропускается.
Строки, которых нет в таблице, из манифеста не удаляются.

## Квоты free tier (проверено 19.10.2026)

- **10 запросов в сутки на модель на проект** (`GenerateRequestsPerDayPerProjectPerModel-FreeTier`, limit 10).
  Сброс в полночь по тихоокеанскому времени (≈ 07:00 UTC). У каждой модели своя квота.
- Поэтому одна просьба = много строк: модель читает пачку фраз с длинными паузами, скрипт режет запись.
  10–13 коротких фраз за запрос — нормально.
- На 429 скрипт ждёт `retryDelay`. Если кончилась **дневная** квота, он останавливается, сохраняет всё
  готовое, пишет, каких строк нет, и выходит с кодом 2. Завтра — тот же запуск: готовое не пересчитывается.
- Журнал запросов: `<cache>/requests.jsonl` (время, модель, голос, статус, длина аудио).

## Модели

| Модель | Статус | Заметки |
|---|---|---|
| `gemini-3.1-flash-tts-preview` | preview, основная по плану | понимает тег `[long pause]`; ответ — голый PCM L16 24 кГц |
| `gemini-3.8-flash-tts` | GA, работает на free tier | ответ — WAV с чанком C2PA (метка происхождения) после аудио; скрипт берёт только `data`. Метка не переживает перекодирование в AAC |
| `gemini-2.5-flash-preview-tts` | preview, запасная | теги пауз не используем (может прочитать их вслух), паузы — пустыми строками |

Голос и модель записаны в манифест; preview-модели могут снять, тогда перерендер — одной командой.

## Как это работает

1. **Пачка → промпт.** Короткий английский блок `### DIRECTOR'S NOTES` (стиль: дружелюбный тренер,
   энергично, но спокойно, чёткая дикция, без музыки) и `#### TRANSCRIPT` — фразы по одной на строке,
   между ними `[long pause]`. Проверено: инструкцию модель вслух не читает.
2. **Разрезка.** Энергия кадров по 10 мс; паузы — кадры ниже «громкий уровень − 32 дБ», короткие тихие
   всплески (вдохи) речью не считаются. N−1 разрезов выбираются динамическим программированием: длинная
   пауза — плюс, длина куска, не похожая на длину текста, — минус. Внутри фраз бывают паузы почти как между
   фразами («Отлично. Держи!», «Три, два, один.»), поэтому одной длины паузы мало. Если запас уверенности
   мал или какой-то кусок не подходит по длине, пачка запрашивается заново половинами.
3. **Обрезка** тишины до 40 мс с каждой стороны (`onsetMs` в манифесте — где начинается речь).
4. **Громкость.** Замер EBU R128 (`loudnorm`, проход 1) → линейное усиление до −16 LUFS → лимитер, если
   пик выходит за потолок → фейды 3 мс → AAC-LC `.m4a`, моно, 24 кГц, 40 кбит/с. AAC на низком битрейте
   добавляет к пикам 2–3 дБ, поэтому истинный пик меряется уже у `.m4a`; если он выше −1,5 dBTP, потолок
   лимитера снижается и клип перекодируется.
5. **Кэш** (`--cache`, по умолчанию во временной папке ОС): `raw/` — ответы API, `lines/` — нарезанные
   фразы. Повторный запуск с другим битрейтом, обрезкой или громкостью запросов не тратит. Кэш в репозиторий
   не кладём.

## Манифест

```json
{
  "default": "Kore",
  "model": "gemini-3.8-flash-tts",
  "generated": "2026-10-19",
  "format": "AAC-LC .m4a, mono, 24000 Hz, 40kbps, -16 LUFS, …",
  "style": "Style: a friendly fitness coach, …",
  "voices": {
    "Kore": {
      "p_go": { "file": "assets/voice/Kore/p_go.m4a", "text": "Начали!", "ms": 590,
                "onsetMs": 40, "model": "gemini-3.8-flash-tts", "hash": "f57947e5aa39" }
    }
  }
}
```

`ms` — длина клипа, `hash` — первые 12 знаков sha256 файла.

## Проверка (`--check`)

Для каждого клипа: длина, секунды на букву, громкость (LUFS), истинный пик, медианная высота голоса (F0),
размер. Флаги: пустой или короче 0,25 с; пик выше −1 dBTP; громкость дальше ±2,5 LU от цели; длина
в 1,6 раза больше или меньше нормы этого голоса; F0 далеко от медианы голоса. Распознавания речи нет:
ударения и «ё» проверяются на слух.

## Известные ограничения

- В Chromium, который ставит Playwright, нет AAC (`canPlayType('audio/mp4; codecs="mp4a.40.2"')` пуст),
  поэтому в e2e-тестах клипы не декодируются и `js/voice.js` переходит на `speechSynthesis`. Chrome,
  Safari, Edge и Android Chrome `.m4a` играют.
- Модель иногда делает длинную паузу внутри фразы из двух предложений. Разрезка это ловит и перезапрашивает
  половины, то есть тратит лишние запросы. Такие фразы лучше не ставить подряд в одну пачку.
- «Три, два, один.» модель читает примерно по секунде на число. Проверка помечает клип как длинный, это
  ожидаемо.
