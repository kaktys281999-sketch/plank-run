# Plank Run — контекст для Claude

Бесплатное веб-приложение (PWA): человек стоит в планке, телефон лежит на полу, игрой управляет корпус.
Распознавание (MediaPipe) работает в браузере, видео и точки тела не покидают устройство.
Владелец пишет по-русски; тексты в интерфейсе — на «ты».

- Живой сайт: https://kaktys281999-sketch.github.io/plank-run/ (GitHub Pages собирает ветку `main`).
- Репозиторий публичный: https://github.com/kaktys281999-sketch/plank-run

## Запуск

```bash
npx serve .                      # или python3 -m http.server 8080; камера работает на localhost
# параметры: ?debug  ?cpu  ?cdn  ?protocol
```

Прототип — ванильные ES-модули без сборки (`index.html`, `js/`, `css/`). Переезд на React + Vite + TS — этапы 1–2 плана (§9.5), не раньше контрольной точки Этапа 0.

## Тесты

```bash
cd test && npm install                  # three.js для синтетического стенда
npx http-server .. -p 8765 -c-1 -s &    # раздаёт корень проекта
curl -o assets/Michelle.glb https://raw.githubusercontent.com/mrdoob/three.js/dev/examples/models/gltf/Michelle.glb
node render-videos.mjs                  # синтетические видео → out/front.y4m, out/side.y4m (фейковая камера)
node e2e.mjs front 40                   # приложение + фейковая камера
node safety.mjs                         # v0.1.1: стоп-вопросы, пределы целей, автоконец
node fireflies-bot.mjs                  # бот ловит светлячков в демо
```

Нужны Playwright с Chromium и ffmpeg. Встроенный в Playwright Chromium не играет AAC: в тестах голос уходит в `speechSynthesis`.

## Правила

- **Безопасность (план §6.5, D2):** тренировочное удержание ≤ 45 с, никаких «держи до отказа» и наград за длину удержания; дисклеймер и стоп-вопросы не обходить. Медицинских обещаний нет; никогда «планка снижает давление».
- **Приватность (D4, D16):** видео, кадры и точки тела не покидают устройство; ответы о здоровье — только на устройстве. Файлы живой проверки — только у владельца, **никогда не в репозиторий** (он публичный).
- **Секреты:** ключи только в переменных окружения или `.env` (в `.gitignore`). Перед пушем — `./tools/check-secrets.sh`. Ключ Gemini, который владелец присылал в чат облачной сессии, нужно перевыпустить.
- **Ветки:** `main` сразу публикуется на GitHub Pages — незаконченное держать в ветках (`wip/*`) и вливать после тестов.
- **Gemini API:** только бесплатный уровень (картинки и Lyria на нём недоступны; TTS работает). Голос генерируется заранее (`tools/tts/generate.mjs`), не из приложения: у API ограничение 18+.
- **Музыка:** без стримингов в игре; только CC0/CC BY и свои файлы пользователя на устройстве (§5 плана).
- Код: маленькие модули, комментарии объясняют «почему»; стиль соседнего кода.
