# art/ — графика Plank Run

Полный план — `docs/plan/spec-visual-art.md`. Промпты — `art/prompts.yaml`.

## Структура

```
art/
  README.md         этот файл
  prompts.yaml      библиотека промптов: prompt_gemini / prompt_chatgpt копировать как есть
  manifest.json     происхождение и версии ассетов (ведёт ассистент)
  canon/            канон-референсы C1–C6 — прикладывать к запросам (см. refs в prompts.yaml)
  inbox/<P-id>/     входящие картинки (только в ветке art-inbox, в main не мержится)
  selects/          отобранные оригиналы
  source/           мастер-SVG и правленые исходники
  processed/        после обработки скриптами
  atlases/          атласы для игр
  contact-sheets/   листы для отбора
```

Готовые файлы для приложения лежат в `assets/`, скрипты обработки — в `scripts/art/`.

## Как генерировать

1. Открой запись в `prompts.yaml` (например, `P07`). Приложи файлы из `canon/`, перечисленные в `refs`.
2. Gemini app: модель Nano Banana Pro, текст `prompt_gemini`. ChatGPT: текст `prompt_chatgpt`.
3. Сделай `variants` вариантов. Одна серия — один чат, назови его «PR · <серия>».
4. Если `background: pair`, вторым сообщением в том же чате отправь `followup_gemini` (тот же кадр на чёрном) и скачай обе картинки.
5. Не больше 20–30 картинок в день и не больше 3 попыток на промпт. Не выходит — напиши ассистенту.

Не нужно:
- писать в Gemini «transparent» (получится нарисованная шахматка);
- вырезать или закрашивать метку Gemini (её убирает только Settings → Media watermark);
- загружать фото людей.

## Как отправить

Скачивай оригинал кнопкой «Скачать» в полном размере. Скриншот не подходит.

1. **В чат с ассистентом (основной путь).** Приложи файлы и подпиши: `P07 gemini 1–2`, `P08 gemini пара 1`. Если Gemini переключился с Pro на обычный Nano Banana, допиши это.
2. **Через GitHub.** Ветка `art-inbox` → папка `art/inbox/P07/` → «Add file → Upload files». Имена файлов:
   - `P07__gemini__1.png`;
   - `P08__gemini__1__white.png` и `P08__gemini__1__black.png`;
   - `P35__chatgpt__2.png`.
3. **Google Drive.** Папка «Plank Run · art inbox», если в сессии подключён Drive.

Дальше ассистент сам посчитает хэши, соберёт контактный лист, а после твоего выбора обработает картинки (альфа, палитра, швы, атласы, сжатие) и запишет происхождение в `manifest.json`.
