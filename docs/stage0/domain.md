# Свой домен для Plank Run (неделя 1)

> **Не понадобилось (20.10.2026, решение D25 в `docs/PLAN.md`).** Постоянный адрес https://plank.erg-team.ru/
> на сервере владельца. Покупать домен и подключать `CNAME` к Pages не нужно. Файл оставлен на случай переезда на свой домен.

Зачем сейчас, а не потом (план, D17): когда у GitHub Pages появляется свой домен, все старые
адреса `kaktys281999-sketch.github.io/plank-run/...` начинают отвечать редиректом 301.
Браузер не обновляет service worker, если его скрипт отдаётся через редирект, поэтому офлайн-PWA
мы включим только на постоянном адресе. Ссылку друзьям тоже лучше сразу давать на домен.

## 1. Выбрать имя

Короткое, латиницей, без дефисов. Варианты для проверки у регистратора:

| Имя | Примерно в год | Комментарий |
|---|---|---|
| `plank.run` | $15–30 | Самое короткое; зона .run |
| `plankrun.app` | $12–20 | Зона .app работает только по HTTPS (Pages это даёт) |
| `plankrun.fun` / `plankrun.games` | $5–30 | Игровые зоны, часто дешёвый первый год, дороже продление |
| `plankrun.uz` | по тарифу регистратора | Если основная аудитория в Узбекистане |
| `plankrun.ru` | 200–1000 ₽ | Если основная аудитория в России |

Свободно ли имя, проверяется только у регистратора (из облачной сессии проверить не получилось).
Смотрите на цену **продления**, а не только первого года.

## 2. Купить

Регистратор должен принимать вашу оплату:

- **Карта России:** REG.RU, RU-CENTER (nic.ru) — продают и .ru, и международные зоны.
- **Узбекистан:** регистраторы зоны .uz (например, Webname, Ahost); международные зоны — через
  регистратора, который принимает вашу карту.
- **Международная карта:** Cloudflare Registrar, Porkbun, Namecheap.

## 3. Настроить DNS (у регистратора, раздел DNS)

Вариант А — адрес вида `www.plankrun.app` (проще):

| Тип | Имя | Значение |
|---|---|---|
| CNAME | `www` | `kaktys281999-sketch.github.io` |

Вариант Б — «голый» домен `plankrun.app` (красивее), добавить все записи:

| Тип | Имя | Значение |
|---|---|---|
| A | `@` | `185.199.108.153` |
| A | `@` | `185.199.109.153` |
| A | `@` | `185.199.110.153` |
| A | `@` | `185.199.111.153` |
| AAAA | `@` | `2606:50c0:8000::153` |
| AAAA | `@` | `2606:50c0:8001::153` |
| AAAA | `@` | `2606:50c0:8002::153` |
| AAAA | `@` | `2606:50c0:8003::153` |
| CNAME | `www` | `kaktys281999-sketch.github.io` |

Адреса GitHub Pages стоит сверить с актуальной страницей документации GitHub
(«Managing a custom domain for your GitHub Pages site») перед вводом.

## 4. Подтвердить домен в GitHub (защита от перехвата)

GitHub → аватар → **Settings** → **Pages** → **Add a domain** → добавить TXT-запись, которую
покажет GitHub, у регистратора → **Verify**.

## 5. Сообщить ассистенту

Напишите в чат выбранный домен. Ассистент добавит файл `CNAME` в репозиторий. Затем в репозитории:
**Settings → Pages → Custom domain** — домен уже будет вписан, дождитесь проверки DNS
(от нескольких минут до суток) и включите **Enforce HTTPS**.

После этого все ссылки (`/?protocol`, `/board/`, `/voices/`) работают на новом адресе,
а старые адреса github.io автоматически перенаправляются.
