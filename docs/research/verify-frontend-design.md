## Что меняет решения

1. **Сборка PWA упадёт, если ничего не настроить.** В vite-plugin-pwa 2.0 действуют шаблон Workbox по умолчанию `**/*.{js,wasm,css,html}` и режим `throwMaximumFileSizeToCacheInBytes`. Поэтому 13,5-МБ `vision_wasm_*.wasm` в `dist` ломает `vite build`, а не пропускается молча. В `injectManifest` нужно явно задать `globPatterns` и `globIgnores`, например исключить `**/wasm/**` и `**/models/**`. Тогда WASM и его JS-загрузчик (около 334 КБ) идут только через runtime-кэш `ml-v{версия}`, как и задумано. Исправить формулировку в frontend.md §8.
2. **Схема с module worker подтверждена, включая ловушку.** Правило «один воркер на модель» остаётся. Ошибку `ModuleFactory not set.` я воспроизвёл, уникальный query её лечит. Чтобы на неё перейти, нужно обновить `vendor/` с 1.0.1 до 1.1.1 и **добавить `vision_wasm_module_internal.{js,wasm}`**, которых сейчас нет. WASM вырастет на ~1,76 МБ (+15 %). Минимальная платформа — iOS 17+, где SIMD есть везде. Значит, классический запасной путь с `vision_bundle.js` и nosimd можно не поставлять. Без SIMD module-путь всё равно сломается: файла `module_nosimd` не существует.
3. **На `outputLatency` в Safari не опираться.** Поддержку с 18.4 подтверждают только таблицы совместимости, у Apple о ней ни слова. Ручная калибровка «тапни в бит» должна быть обязательной на всех платформах, а не запасным вариантом. Значение `outputLatency` используем как начальное приближение.
4. **Поддержка Ogg зависит от ОС, а не от версии Safari.** Нужны macOS Sequoia 15.4+ или iOS 18.4+. Воспроизведение Ogg из Blob исправлено только в 26.4, а Opus в MP4 через `decodeAudioData` — только в 27. Решение «библиотека в AAC/MP3, пользовательские файлы проверяем пробным декодированием» остаётся. Для загрузок формулировку «Ogg с 18.4» лучше заменить на «Ogg не обещаем, проверяем декодированием».
5. **Push и установка на iOS.** Добавить в план Declarative Web Push (Safari 18.4+): на iOS он надёжнее классического push через Service Worker. С iOS 26 «На экран Домой» по умолчанию создаёт веб-приложение, поэтому инструкцию по установке можно упростить. Но push по-прежнему требует манифест с `display: standalone`. В план тестов стоит добавить iOS 27 как текущую версию.
6. **Мелочи для документов.**
   - TypeScript: latest — 7.0.2, официальный пример MediaPipe уже на TS 7. Выбор «TS 6.0 + typescript-eslint» или «TS 7 + Biome» нужно сделать явно.
   - Montserrat, Nunito и Tektur тоже под OFL, так что направления B и C тоже обходятся без лицензионных затрат.
   - По WCAG цель — AA. 2.3.3 (AAA) делаем по желанию. Лимит вспышек оставляем консервативным: небольшой пульс по сильным долям нормален.
   - Rive и GSAP подтверждены, решения по ним не меняются: маскот на SVG + Motion, Rive при бюджете $9–17 в месяц, GSAP допустим.
