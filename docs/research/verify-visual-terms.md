## Что меняет решения

1. **Gemini может быть основным инструментом для производства, а не только для мудбордов.** Переключатель метки подтверждён официальной справкой и для AI Pro вне Индии, Кореи и Вьетнама должен быть доступен. План «если переключателя нет — производство в ChatGPT» остаётся запасным. Новое правило: всё, что сгенерировано **до** выключения метки, в производство не идёт, а генерируется заново.
2. **Вызывать Gemini API во время работы приложения нельзя, пока в нём есть люди младше 18 лет.** В журнал решений стоит добавить пункт: «Gemini API — только для заранее отрендеренного контента; рендерит взрослый разработчик из поддерживаемой страны; приложение и сервер API не вызывают». Это закрывает «живого тренера», ИИ-разбор для игроков и подобные функции на Gemini API. Если такие функции понадобятся — другой провайдер или отдельный режим 18+ после юридической проверки.
3. **Запасной голос — только `v5_cis_base` / `v5_cis_base_nostress` (MIT).** Узбекский голос — только `uzb_saida`. В §8.5 и §8.8 исправить `v5_x_ru` на «`v5_ru`…`v5_6_ru` — CC BY-NC-SA 4.0». Скрипт должен проверять имя пакета: `v5_cis_ext`, `v5_turkic` и `v5_*_ru` запрещены. Ударения — вручную, это заложить в объём работ.
4. **Регион владельца — главный риск, и тест ключом его не снимает.** Узбекистан поддерживается всеми тремя сервисами: Gemini app, Gemini API и ChatGPT. ## Что сделать владельцу

1. **День 0, скриншоты.**
   - Gemini → Settings → **Media watermark**. На скриншоте должны быть видны сам переключатель и тариф (AI Pro).

6. **Не делать:** не обрезать и не закрашивать метку на старых картинках; не загружать фото людей; не включать в TTS имена и данные пользователей.
